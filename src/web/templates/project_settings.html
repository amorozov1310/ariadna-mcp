Как обновлять данные

Выгрузите конфигурацию из Конфигуратора («Конфигурация → Выгрузить конфигурацию в файлы») и загрузите XML на странице обзора — через «Изменить» у источника или «Добавить источник». Отчёт по конфигурации выгружать не нужно, он строится из XML сам. После загрузки нажмите «Переиндексировать».
