    Как устроен доступ
    

        
Личный токен — у каждого человека и робота свой. В Web UI с ним входят на странице «Вход»,
            агент передаёт его в заголовке Authorization: Bearer …
            (в настройке MCP-сервера — "headers").

        
Администратор — проекты, их состав и удаление, токены, лицензия;
            участник — поиск, все инструменты чтения, обновление индекса, словарь.

        
Без лицензии — один токен (закрыть свой сервер бесплатно); токены для команды — по ключу.
            Подробно — docs/team.md.
