# ADR 0002. Инструмент semantic_search_code

Статус: принято, 2026-10-30. Опирается на [ADR 0001](0001-standalone-1x.md)
и замеры в [hybrid-search.md](../hybrid-search.md).

## Контекст

Агенту нужен поиск процедур по описанию своими словами («где считается
себестоимость»). Существующие `search_procedures` (подстрока в имени) и
`search_code` (подстрока в тексте) на таких вопросах почти ничего не
находят: на наборе из 35 вопросов к крупной конфигурации hit@10 — 12% и
3%. Поиск по карточкам процедур (BM25 с корнями слов, приоритетом точного
имени, экспорта и востребованности) — 79%. Векторы пока не нужны: прирост
от них не измерен, а без них нет зависимостей и офлайн-поставки модели.

## Решение

Новый, 17-й инструмент `semantic_search_code`; 16 инструментов 1.0 не
меняются (снимок `tests/contract_1x.json`, совместимое дополнение 1.x).

Параметры: `query` (обязательный), `project_id`, `source_id`, `limit`
(по умолчанию 10, не больше 50 — больший урезается с предупреждением),
`offset` (0). Выбор проекта — как у остальных инструментов.

Ответ — текст и `structuredContent` с опубликованной `outputSchema`
(`SemanticSearchResult` в `src/mcp_server/server.py`); оба описывают один
результат: текст — компактная выдача для модели, структура — для программных
клиентов:

- `schema_version` ("1"), `project_id`, `query`;
- `search_mode` — фактический режим (`lexical`; в будущем `hybrid`,
  `vector`), `mode_reason` — почему такой;
- `freshness` — `index_state`, `indexed_at`, `card_format`;
- `items` — процедуры: `rank`, `entity_id` (устойчивый между
  переиндексациями: хеш источника, модуля и имени), `source_id`, `kind`,
  `module_name`, `procedure_name`, `is_export`, `relative_path`
  (относительно корня выгрузки — абсолютные пути хоста не выдаются),
  строки процедуры и найденного фрагмента, `content_hash` карточки,
  `match_methods` (`exact_name` | `fts`), `evidence_kind`
  (`source_excerpt` | `card_header`), `snippet` и его строка;
- `offset`, `limit`, `has_more`, `next_offset` — та же пагинация, что у
  остальных (`use offset=N for more` в тексте);
- `warnings` — урезанный limit, идущая переиндексация, карточки прежнего
  формата, недоступные файлы.

Ошибки — `isError`, как у остальных: неизвестный проект или источник,
пустой запрос, **индекс карточек не построен** (не пустая выдача, а
совет переиндексировать).

Логика — `src/mcp_server/semantic_search.py` и
`tools.semantic_search_payload` (без SDK), Web UI (playground) получает тот
же текст через `tools.execute_tool`.

## Следствия

- Векторная ветка, если появится, — режим этого же инструмента
  (`search_mode`), без новых инструментов; бэкенд эмбеддингов — внешний
  OpenAI-совместимый эндпоинт (vLLM, Ollama, облачный), включаемый в
  настройках проекта.
- Шаблоны правил агента (`docs/agent-rules`) направляют поиск по описанию
  сюда, а не «в другой сервер».
- Изменение формата ответа — только совместимые дополнения; несовместимое —
  новая `schema_version`.
